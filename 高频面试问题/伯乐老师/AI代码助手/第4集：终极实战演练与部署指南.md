<font style="color:rgb(26, 28, 30);">为了验证 AI 到底是不是在“胡说八道”，我们需要一段逻辑通顺但隐患重重的代码。请在演示时复制以下代码放入你的系统。</font>

### <font style="color:rgb(26, 28, 30);">1.1 测试样本 (UserUtils.java)</font>
**<font style="color:rgb(93, 93, 95);">code</font>****<font style="color:rgb(28, 27, 27);">Java</font>**

```plain
public class UserUtils {
    // 这是一个充满槽点的代码片段
    public String handle(List<String> list, String type) {
        String s = "";
        
        // ❌ 槽点1：使用 == 比较字符串 (这是 Java 新手最容易犯的错)
        if (type == "VIP") {
            // ❌ 槽点2：没有判空，如果 list 为 null，下面会报 NPE
            for (int i = 0; i < list.size(); i++) {
                String u = list.get(i);
                // ❌ 槽点3：魔法数字 5，应该定义常量
                if (u.length() > 5) {
                    // ❌ 槽点4：在循环中进行 String 拼接，性能极差 (O(n^2))
                    s = s + u + ",";
                    // ❌ 槽点5：生产环境禁止使用 System.out 打印日志
                    System.out.println("Add user: " + u);
                }
            }
        } else {
            // ❌ 槽点6：返回 null 会导致调用方空指针，应返回空字符串
            return null;
        }
        return s;
    }
}
```

## <font style="color:rgb(26, 28, 30);">2. </font><font style="color:rgb(26, 28, 30);">📦</font><font style="color:rgb(26, 28, 30);"> 项目打包与脱离 IDE 运行</font>
<font style="color:rgb(26, 28, 30);">开发完成后，我们要把它打包成一个可执行文件，这样你发给同事，或者部署到服务器上都能跑。</font>

### <font style="color:rgb(26, 28, 30);">2.1 这里的坑：Maven 打包配置</font>
<font style="color:rgb(26, 28, 30);">确保你的</font><font style="color:rgb(26, 28, 30);"> </font><font style="color:rgb(50, 48, 44);">pom.xml</font><font style="color:rgb(26, 28, 30);"> </font><font style="color:rgb(26, 28, 30);">里有 Spring Boot 的打包插件（Cursor 生成的代码通常自带，但需检查）：</font>

**<font style="color:rgb(93, 93, 95);">code</font>****<font style="color:rgb(28, 27, 27);">Xml</font>**

```plain
<build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
            <configuration>
                <excludes>
                    <exclude>
                        <groupId>org.projectlombok</groupId>
                        <artifactId>lombok</artifactId>
                    </exclude>
                </excludes>
            </configuration>
        </plugin>
    </plugins>
</build>
```

### <font style="color:rgb(26, 28, 30);">2.2 执行打包命令</font>
<font style="color:rgb(26, 28, 30);">打开终端 (Terminal)，进入项目根目录，运行：</font>

**<font style="color:rgb(93, 93, 95);">code</font>****<font style="color:rgb(28, 27, 27);">Bash</font>**

```plain
# -DskipTests 表示跳过单元测试（防止测试用例报错卡住打包）
mvn clean package -DskipTests
```
