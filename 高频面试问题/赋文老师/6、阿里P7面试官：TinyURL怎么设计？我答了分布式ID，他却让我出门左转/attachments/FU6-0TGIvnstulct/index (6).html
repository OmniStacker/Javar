第二关：如何扛住【高并发读】？

🧠

核心思想：引入缓存（Redis）

请求 ➡️ [ Redis? ] ─╮
命中 ✅ (99%) ───╯
未命中 ❌ ─→ [ DB ] ─→ 写回Redis

进阶考验：如何防止【缓存穿透】？

👿

黑客用不存在的Key疯狂攻击

请求 ➡️ [ Redis (Miss) ] ➡️ [ DB (Miss) ]
请求 ➡️ [ Redis (Miss) ] ➡️ [ DB (Miss) ]
请求 ➡️ [ Redis (Miss) ] ➡️ [ DB (Miss) ] ➡️ 🔥

解决方案：【缓存空值】

🛡️

查不到？把“空”也缓存起来！

首次请求 ➡️ DB(Miss) ➡️ 在Redis缓存 "NULL"

后续攻击 ➡️ [ Redis (Hit "NULL") ] ➡️ 直接返回 🛑
