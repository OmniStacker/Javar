## 1. 网络基础

### 1.1 什么是IP地址？IPv4和IPv6有什么区别？

**IPv4**：32位地址，约43亿个

**IPv6**：128位地址，几乎无限

### 1.2 什么是网络延迟和带宽？

**延迟**：数据从发送到接收的时间

**带宽**：单位时间内传输的数据量

### 1.3 什么是DNS？

**DNS（域名系统）**：将域名解析为IP地址

## 2. TCP/IP协议

### 2.1 TCP和UDP协议的区别？

| 特性 | TCP | UDP |
|------|-----|-----|
| **连接** | 面向连接 | 无连接 |
| **可靠性** | 可靠 | 不可靠 |
| **顺序** | 有序 | 无序 |
| **速度** | 慢 | 快 |
| **开销** | 大 | 小 |

### 2.2 TCP/IP协议栈？

**四层模型**：
1. 应用层：HTTP、FTP、DNS
2. 传输层：TCP、UDP
3. 网络层：IP、ICMP
4. 链路层：以太网、WiFi

### 2.3 TCP粘包和拆包问题？

**粘包**：多个消息粘在一起

**拆包**：一个消息被拆成多个

**解决方案**：
1. 固定长度
2. 分隔符
3. 消息头+消息体

## 3. HTTP协议

### 3.1 什么是HTTP协议？

**HTTP（超文本传输协议）**：应用层协议，基于请求-响应模型

### 3.2 HTTP状态码？

**2xx**：成功（200 OK）

**3xx**：重定向（301、302）

**4xx**：客户端错误（400、401、403、404）

**5xx**：服务器错误（500、502、503）

### 3.3 HTTPS与HTTP的区别？

**HTTPS**：HTTP + SSL/TLS，加密传输

### 3.4 为什么有了HTTP，还需要WebSocket？

**HTTP**：单向通信，客户端请求

**WebSocket**：双向通信，服务器可主动推送

### 3.5 什么是Cookie？

**Cookie**：存储在客户端的小数据，用于会话管理

### 3.6 什么是CORS？

**CORS（跨域资源共享）**：解决跨域问题

## 4. I/O模型

### 4.1 阻塞I/O和非阻塞I/O的区别？

**阻塞I/O**：等待数据就绪

**非阻塞I/O**：立即返回，轮询检查

### 4.2 同步I/O和异步I/O的区别？

**同步I/O**：应用等待数据拷贝

**异步I/O**：应用发起请求，数据就绪后通知

### 4.3 什么是I/O多路复用？

**I/O多路复用**：一个线程监控多个文件描述符

**实现方式**：select、poll、epoll

### 4.4 select、poll和epoll的区别？

| 特性 | select | poll | epoll |
|------|--------|------|-------|
| **最大连接** | 1024 | 无限制 | 无限制 |
| **效率** | O(n) | O(n) | O(1) |
| **内存拷贝** | 是 | 是 | 否 |

### 4.5 什么是零拷贝？

**零拷贝**：数据不经过CPU拷贝，直接从磁盘到网卡

**实现方式**：sendfile、mmap

## 5. 网络编程

### 5.1 Java中NIO与传统I/O的区别？

| 特性 | 传统I/O | NIO |
|------|---------|-----|
| **模型** | 阻塞 | 非阻塞 |
| **缓冲区** | 无 | 有 |
| **通道** | 无 | 有 |
| **选择器** | 无 | 有 |

### 5.2 NIO核心组件？

1. **Channel**：通道
2. **Buffer**：缓冲区
3. **Selector**：选择器

### 5.3 什么是缓冲区？

**缓冲区**：内存区域，用于暂存数据

**作用**：减少I/O次数，提高性能

### 5.4 什么是流？

**流**：数据的有序序列

**InputStream**：输入流

**OutputStream**：输出流

## 6. 网络安全

### 6.1 什么是CSRF攻击？

**CSRF（跨站请求伪造）**：伪造用户请求

**防护**：
1. 验证码
2. Referer检查
3. Token验证
