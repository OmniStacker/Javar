# 无标题文档





**<font style="color:rgba(0, 0, 0, 0.88);">口播文案</font>**

<font style="color:rgba(0, 0, 0, 0.88);">朋友们，有个面试题几乎百分百会被问到：“你们项目为啥用Kafka不用RocketMQ？”或者反过来：“为啥用RocketMQ不用Kafka呀？”</font>

<font style="color:rgba(0, 0, 0, 0.88);">是不是一听就头大？别担心！这题其实不是在考你背书，而是在看你会不会“看菜下饭”。</font>

**<font style="color:rgba(0, 0, 0, 0.88);">记住一句大实话：技术没有好坏，只有合不合适！</font>**

**<font style="color:rgba(0, 0, 0, 0.88);">如果你干的是这种事：</font>**<font style="color:rgba(0, 0, 0, 0.88);"> 天天处理海量日志、用户点击流、或者APP监控数据——数据量大到爆炸，速度必须快！</font>

**<font style="color:rgba(0, 0, 0, 0.88);">那你就可以这么说：</font>**<font style="color:rgba(0, 0, 0, 0.88);"> “哎，我们那场景太猛了，每天数据跟洪水似的！必须得上Kafka这匹‘千里马’啊！它处理这种海量数据最在行了，而且最后数据都要跑到Flink那边去，它俩是‘黄金搭档’，配合起来贼顺畅！”</font>

**<font style="color:rgba(0, 0, 0, 0.88);">如果你干的是这种事：</font>**<font style="color:rgba(0, 0, 0, 0.88);"> 搞电商下单、支付、积分兑换——消息一条都不能丢，还得支持延时消息或者事务。</font>

**<font style="color:rgba(0, 0, 0, 0.88);">那你就可以这么说：</font>**<font style="color:rgba(0, 0, 0, 0.88);"> “我们这业务可精细了，消息可不能玩消失！RocketMQ自带‘事务消息’技能，我们做下单流程特别顺手。而且它全是Java写的，我们排查问题、看源码什么的特别友好。它那个管理后台还能直接看消息到哪了，运维小哥都说好！”</font>

**<font style="color:rgba(0, 0, 0, 0.88);">说白了就一句话：因为我们的业务是XX样的，所以这个技术特别配！</font>**

<font style="color:rgba(0, 0, 0, 0.88);">别再死记硬背参数对比了。你就告诉面试官：“Kafka是搞数据洪流的，RocketMQ是搞精细业务的。我们不是选哪个更好，而是选哪个更合适！”</font>

**<font style="color:rgba(0, 0, 0, 0.88);">最后考考你：你现在做的项目，要是让你挑消息队列，你会选谁？评论区聊聊！</font>**

**<font style="color:rgba(0, 0, 0, 0.88);">觉得有用记得点个赞，收藏一下，下次面试前保准用得上！</font>**
