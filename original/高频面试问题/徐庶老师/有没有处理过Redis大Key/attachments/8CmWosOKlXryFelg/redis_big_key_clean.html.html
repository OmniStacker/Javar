第四章：大 Key "温柔删除法"——避免直接 DEL

String: 迁移

将大文件存入OSS/S3，Redis只存URL。

Hash/Set: 渐进式删除

使用 HSCAN / SSCAN 分批删除。

List: 分段裁剪

使用 LTRIM 循环裁剪。
