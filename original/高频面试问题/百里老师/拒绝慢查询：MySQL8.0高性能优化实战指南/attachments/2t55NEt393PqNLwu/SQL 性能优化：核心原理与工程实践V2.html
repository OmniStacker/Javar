SQL 优化三大铁律

少扫描

Scan Less

  • 覆盖索引 (Covering Index)
  • 拒绝回表 (No Table Lookup)
  • Full Table Scan

少返回

Return Less

  • 只查需要的列
  • LIMIT 分页
  • SELECT *

少交互

Interact Less

  • 批量插入 (Batch Insert)
  • 存储过程 / 复杂 SQL
  • Loop { INSERT }
