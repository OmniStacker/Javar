Lambda初见：一行代码搞定集合排序

从“模板代码”的泥潭到“核心逻辑”的精炼。

传统写法：模板代码占90%


new Comparator<String>() {
    @Override
    public int compare(String o1, String o2) {
        return o1.compareTo(o2); // <-- 核心逻辑
    }
});
Refactor

Lambda写法：100% 核心逻辑


(o1, o2) -> o1.compareTo(o2)

Stream API三大核心操作：Filter, Map, Reduce

构成数据处理流水线的三驾马车。

Filter (过滤)

["🍎", "🍋", "🥕"]

.filter(isFruit)

["🍎", "🍋"]

Map (映射)

["Apple", "Sun"]

.map(String::length)

[5, 3]

Reduce (规约)

[1, 2, 3, 4, 5]

.reduce(0, Integer::sum)

15

组合的力量：构建Stream数据处理流水线

将复杂操作串联成优雅的链式调用。

需求：筛选活跃用户，获取并处理其邮箱

用户列表

.filter()

.map()

.sorted()

.distinct()

最终结果

users.stream()
   .filter(user -> user.isActive())
   .map(User::getEmail)
   .map(String::toUpperCase)
   .distinct()
   .sorted()
   .collect(Collectors.toList());

进阶应用：用Lambda简化并发与空指针处理

将函数式思想融入日常开发，提升代码质量。

1. 并发编程

传统方式


new Runnable() {
  @Override
  public void run() {
    doWork();
  }
}

Lambda 方式


() -> doWork()

2. 健壮性设计 (Optional)

传统方式


if (user != null) {
  return user.getName();
} else {
  return "default";
}

Optional 方式


user.map(User::getName)
    .orElse("default")
